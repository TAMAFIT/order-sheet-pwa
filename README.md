# 手書き注文 集計アシスタント — 凍結保存

> **Status: FROZEN / EXPERIMENTAL**  
> このプロジェクトは 2026-08-15 に実証を終了し、開発を凍結しました。公開PWAは資料・再現・将来の再利用のため残しています。本番業務への利用は推奨しません。

固定フォーマットの手書き注文票を、Custom GPTの画像解析から構造化し、GPT Action → Cloudflare Worker/KV → PWAへ返して商品別に集計する実証プロジェクトです。

## 終結理由

PWA、Custom GPT Action、SCAN_IDによる結果返却、Cloudflare Worker/KV、集計・要確認・編集・履歴などの周辺システムは成立しました。

一方、実際の日本語手書き注文票では、商品名・数量・注文者境界・二次元の読み順をVisionモデルが常に十分な精度で認識することが難しく、実用に必要な安定性を確保できませんでした。人間の確認工程を増やせば運用できますが、本来の省力化メリットが小さくなるため、手書き注文票用途としては一旦終了します。

## 重要な技術資産

このリポジトリで最も再利用価値が高いのは、手書きOCRそのものではなく、以下の書類AI処理パイプラインです。

```text
画像 / PDF相当の入力
  ↓
専用Custom GPT / AI解析
  ↓
SCAN_IDで処理単位を識別
  ↓
submitScanResult Action
  ↓
Cloudflare Worker
  ↓
KVへ一時保存
  ↓
元のPWAが結果取得
  ↓
自動集計
  ↓
怪しい項目だけ要確認
  ↓
編集・削除・履歴・出力
```

この構成は、将来の**領収書・レシート・請求書・PDF・JPEG・スクリーンショット等の確定申告向け自動集計**へ転用する候補です。印字された文書は、今回の崩した手書き日本語より入力品質が安定するため、別用途として再評価する価値があります。

## 最終版で実装済みだった主な機能

- スマホ撮影 / 端末画像選択 / 上下分割撮影

- 専用Custom GPTへの引き渡し

- 修正内容の集計への即時反映
- セッション履歴・復元
- ローカル商品DB / 別表記学習
- イオン綾川公開カタログのローカル検索基盤
- JSONバックアップ / インポート
- PWA / GitHub Pages

## セキュリティ

APIキー、Action認証キー、OAuth token、パスワード等のSecretはリポジトリへ保存しません。クライアントコードにSecretを埋め込まない方針を維持してください。

## 開発再開時の原則

1. まず `archive/final-v0.1.19-2026-08-15` と `docs/PROJECT_CLOSEOUT.md` を確認する。
2. 手書きOCR用途を再開する場合は、モデル精度が改善したことを実データで先に検証する。
3. 別の書類処理用途では、既存のSCAN_ID / Action / Worker / 結果復帰 / 要確認UIを土台として利用する。
4. mainを直接改変せず、新しいブランチから再開する。
