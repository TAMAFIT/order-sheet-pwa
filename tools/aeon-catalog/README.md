# AEON綾川店 商品候補辞書収集

イオンネットスーパーの公開ページから、注文票PWAの候補辞書に使うための JAN・商品名・カテゴリ・価格・出典URLを低頻度で収集する一回限りのツールです。

- 対象: イオン綾川店 `01050000070020`
- 公開ページのみ
- `robots.txt` を確認し、対象パスが禁止なら停止
- 逐次アクセス + 待機時間 + 429/503バックオフ
- ログイン、カート、注文、個人情報ページにはアクセスしない
- 出力: `products.json`, `products.csv`, `categories.json`, `meta.json`

ネットスーパー掲載商品と移動販売車の実在庫は一致するとは限らないため、このデータは「候補辞書」として扱い、実運用で確認された商品をPWA側の確定商品DBへ昇格させます。
